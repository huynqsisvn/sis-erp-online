# FXBCCCTH5 - Bảng kê thông tin chung CCDC

## Thông tin
- **Menu ID**: wf.xb.11
- **Page**: fxbcccth5
- **Store Procedure**: FxBcCcTh5 (tham số: nam, ky, dau_cuoi, ma_bpcc, cKey)

## Files
- **FXBCCCTH5.cs**: Model dữ liệu (FXBCCCTH5Model, FXBCCCTH5Row)
- **FXBCCCTH5Cpn.razor**: Component chính (form lọc + lưới kết quả)

## Chức năng
- Bảng kê thông tin chung CCDC theo kỳ/năm
- Lọc theo đầu kỳ hoặc cuối kỳ
- Lọc nâng cao: nhóm cc, loại cc, mã bpcc, tk cp, nhóm cc 1/2/3
- Kết xuất Excel (toolbar Export)
- In báo cáo (toolbar Print / F7)
- Phím tắt: F7 (In), Ctrl+F (Mở bộ lọc)
