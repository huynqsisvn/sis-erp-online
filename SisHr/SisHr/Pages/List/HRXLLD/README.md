# HRXLLD - Danh mục Xếp loại lao động

## Mô tả
Chức năng quản lý danh mục xếp loại lao động (menu `wr.dm.02`, trang `hrxlld`).

## Các file
- `Dmxlld.cs` – Model dữ liệu
- `HrxlldComponent.razor` – Trang danh sách
- `EditHrxlld.razor` – Form thêm/sửa/xem
- `FrmHrxlld.razor` – Popup wrapper

## Chức năng
Thêm, sửa, xem, copy, đổi mã, kết xuất, xóa. Validate không xóa khi đã phát sinh.
